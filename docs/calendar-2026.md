# Календарь мероприятий ГЭС-2 — до конца 2026 года

Собрано: 09.08.2026. **Источник — не HTML-страница, а GraphQL API сайта**, тот же, которым сам сайт наполняет календарь (`ges-2.org/graphql`, `operationName=newMaterialsInterval`). Это надёжнее скрейпинга вёрстки: данные структурированы (тип, даты начала/конца, платность), не бьются при редизайне страницы.

**Как обновить самостоятельно:**
```bash
python3 tools/fetch_calendar.py --from 2026-08-09 --to 2026-12-31 --out docs/calendar-data.json
```
Скрипт — [tools/fetch_calendar.py](../tools/fetch_calendar.py), без внешних зависимостей (только стандартная библиотека Python 3). Флаг `--csv` выгружает в CSV для Excel/Sheets.

**Важная оговорка про горизонт:** сайт публикует события примерно на 3–4 месяца вперёд. На момент сбора данных дальше всего заявлено «След в воздухе» (мастер-класс, до 29.11.2026) и несколько программ до середины декабря. **Событий на декабрь 2026 (после ~10 числа) сайт пока не публикует** — их стоит досверить у заказчика напрямую или перепарсить ближе к дате.

Итого в диапазоне 09.08–31.12.2026: **72 материала** (выставки, кинопоказы, концерты, мастер-классы, лаборатории, регулярные форматы).

## Ключевые операционные точки

- **Три текущие выставки закрываются почти одновременно**: «Весь мир здесь обретает дом: по следам Тагора» — 23.08, «Хадзар мечты» — 13.09, «Москва — Ханой. Ландшафты оптимизма» — 20.09.
- **Следующая выставка** — «Натюрморт. Портрет. Пейзаж. После жанра» — открывается только **15.10.2026** и идёт до 25.04.2027.
- Между закрытием последней текущей выставки (13.09) и открытием следующей (15.10) — **окно около месяца** на демонтаж/монтаж. Стоит сверить с командой технического производства, устраивает ли этот интервал план работ, или это узкое место.
- **«ГЭС-2 Саундсистем 4»** (24–30.08) — крупный музыкальный уикенд из трёх частей (Mind/Body/Spirit) плюс сопутствующая «Песни Палисадника» — потенциально высоконагруженный период для посетительского сервиса и парковки.
- **«Гала. Пять лет музыки»** (07.09–16.12) — юбилейная музыкальная программа, самая долгая из объявленных.

## Регулярные/фоновые форматы (идут постоянно, не привязаны к разовой дате)
