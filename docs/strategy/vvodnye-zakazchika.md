## Цели

**Постепенный выход на зарабатывание денег.** Цель поставлена Советом директоров. Формулировка: «чем дальше, тем лучше» — то есть это направление движения с растущей планкой, а не разовый целевой показатель.
_Источник: заказчик, сентябрь 2026._

Следствия для метрик:
- Self-generated income переходит из «операционных» метрик в целевые.
- Платный вход с 13.11.2025 — не разовое изменение ценовой политики, а первый шаг этого курса.
- Earned Growth Rate (NPS 3.0), который отчёт по метрикам счёл неприменимым «для бесплатного/миссийного входа», при этом курсе становится обсуждаемым — но не раньше, чем появится устойчивая платная база.

## Трактовки, согласованные с заказчиком
