## Ограничения
- «Перформанс» отнесён сразу к двум категориям (Концерт и Танцевальный показ) — сайт не уточняет вид перформанса.
- Раздел «Прочее» выделен отдельно: образовательно-игровые/детские форматы не ложатся однозначно ни в одну из 6 заданных категорий.
- Группировка сделана вручную по смыслу названий из общего фильтра «Тип» на /calendar — сайт не даёт готовой иерархии «категория → виды».
- Проверка на живых данных (/calendar) охватила только 09.08.2026 — в этот день не было событий типа «Концерт», «Танец» или «Лекция»; типы подтверждены через справочник фильтра.
