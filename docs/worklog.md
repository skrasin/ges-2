# Журнал работы по проекту

Что уже сделано, какие решения приняты и почему. Этот файл заменяет историю чата:
переписка Claude Code хранится локально на конкретной машине и в другой сессии
или на другом устройстве недоступна — поэтому всё существенное фиксируется здесь.

Порядок — от старого к новому.

---

## 1. Настройка работы и анализ сайта

- Решили не создавать отдельное пространство/коннекторы: работаем на удалённом доступе,
  документы передаются вручную в `docs/`. Постоянный контекст — в `CLAUDE.md`.
- `docs/site-analysis.md` — разбор ges-2.org: структура, разделы, типы материалов,
  что можно вытащить программно.
- `docs/org-map.md` — функциональная карта: кто за что отвечает. Составлена по публичным
  источникам, не по внутренним регламентам — при появлении официальной оргструктуры требует сверки.

## 2. Календарь событий

- У сайта есть GraphQL API — календарь собирается программно, не парсингом HTML.
- `tools/fetch_calendar.py` → `docs/calendar-data.json` → `docs/calendar-2026.md` +
  `tools/build_calendar_xlsx.py` → `docs/calendar-2026.xlsx`.
- **Найденный баг источника**: поле `fullPath` у материалов типа «событие» содержит
  внутренний CMS-префикс `ges2/`, которого нет в публичном URL (проверено curl:
  `/ges2/<slug>` → 404, `/<slug>` → 200). Префикс `projects/<slug>` — настоящий, его
  трогать нельзя. Лечится хелпером `public_path()` в `fetch_calendar.py`.

## 3. Дизайн-система

- Официальных бренд-гайдлайнов и файлов шрифта у нас нет. Дизайн-система **восстановлена
  обратным инжинирингом живого сайта** через `getComputedStyle()` — имена классов на проде
  хэшированы, читать CSS бессмысленно. Методология описана в конце `design-system/design-system.md`.
- Ключевое: монохром (чёрное на белом), `border-radius: 0` везде, hairline-разделители 0.5px,
  фирменного цветного акцента нет — иерархия держится на типографике.
- Шрифт **Diagramatika Text/Display** — проприетарный, файлов нет и быть не должно без лицензии.
  Во всех материалах используется fallback (`Helvetica Neue` / `Arial`) с явной оговоркой.
- Более ранние артефакты («Функциональная карта», «Календарь») делались в моей выдуманной
  зелёной палитре — она к бренду ГЭС-2 отношения не имеет. При необходимости переделываются.

## 4. Автономные HTML-инструменты

Три самодостаточных файла — все данные вшиты внутрь, открываются без сервера и интернета:

- `knowledge-base/` — база знаний службы по работе с посетителями (84 ответа), сборка `build_kb.py`
  с валидацией целостности данных на входе.
- `event-management/` — реестр событий: категории, треки, этапы, RACI. Логика «текущего этапа»
  восстановлена эмпирически из исходного Excel-шаблона, а не задана заново.
- `surveys/visitor-survey-basic.html` — анкета посетителя (CSAT, CES, NPS + 2 открытых вопроса).

Адаптивность под телефон у реестра ограничена — обсуждали, решили пока не чинить.

## 5. Архив документов ГЭС-2 / V–A–C

- 87 PDF в `docs/documents-ges2-vac/`, разложены по 4 папкам, имена файлов расшифрованы.
- `docs/press-archive-analysis.md` — разбор: реальная оргструктура с именами, KPI посещаемости,
  смена ценовой политики, операционные нормативы программ, партнёрства, календарь фестивалей.
- `_extracted-text.json` — полнотекст всех PDF для поиска без повторного разбора.

## 7. Презентации: уточнение дизайн-системы и шаблон

Исходники — две реальные колоды: «Предложение по организации концертов» (33 слайда,
чисто внутренняя) и презентация к мероприятию 22.10.2024 (10 слайдов, совместная
с «Газпромбанк»).

- В песочнице нет poppler/LibreOffice — PDF разбирались через `pymupdf` (рендер страниц
  в PNG + извлечение вложенных изображений с дедупликацией по MD5).
- `design-system/design-system.md` §9 — формат слайда 16:9, хлебная крошка, нумерация,
  7 типов вёрстки слайдов.
- **Найдено в презентациях, чего нет на сайте**: пара цветов для выносок на планах
  помещений — `#0075B9` (синий) и `#B41700` (тёмно-красный), подтверждены пиксельным
  замером на двух разных слайдах-планах. Добавлены в `tokens.css` как токены
  **только для схем**: общий принцип «нет фирменного цвета» для продукта не отменяется.
- **Шрифт в колодах — не Diagramatika и не Helvetica**, а геометрический гротеск,
  одинаковый в обеих независимых колодах. Файл не опознан. Шаблон собран на Arial с оговоркой.
- `design-system/photos/` (13 фото) и `design-system/diagrams/` (3 схемы этажей).
  Логотип «Газпромбанка» из партнёрской колоды **намеренно исключён** — чужой товарный знак,
  не бренд-актив ГЭС-2. Шаблон сделан универсальным, без партнёрской символики.
- `design-system/ges2-presentation-template.pptx` — 8 слайдов, собирается
  `build_presentation_template.py`. Правки вносить в скрипт, не в .pptx (перезаписывается).

## Повторяющиеся технические грабли

Каждая всплывала минимум дважды — проверять до, а не после.

- **openpyxl съедает цвет.** Шестизначный hex (`"000000"`) молча дополняется до `00RRGGBB`,
  то есть alpha = 0, полностью прозрачно. Всегда писать 8 знаков с `FF` впереди: `"FF000000"`.
- **Ссылки `/ges2/`** — см. раздел 2. Проверять при любом новом импорте данных с сайта.
- **`--ges2-scale` без `/1px`.** Без деления коэффициент остаётся длиной, `calc(длина × длина)`
  невалиден, свойство молча откатывается к начальному значению. Баг незаметный, ловился глазами.
- **Песочница.** Нет `gh`, LibreOffice, `pdftoppm`, `brew`. Обход всегда один: `pip install`
  чистого Python-аналога (`openpyxl`, `pypdf`, `pymupdf`, `python-pptx`).
- **Счётчики страниц в system-reminder про PDF врут** (обещали 14 и 128 страниц, по факту 7 и 10).
  Верить `len(doc)` из библиотеки, а не метаданным напоминания.
