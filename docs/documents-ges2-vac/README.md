# Архив документов ГЭС-2 / V–A–C

87 PDF (пресс-релизы 2022–2026 + институциональные/стратегические материалы), разложены по 4 папкам: `exhibitions/`, `events-and-festivals/`, `partnerships-and-business/`, `strategy-and-policies/`.

- **Разбор и выводы** — см. [`../press-archive-analysis.md`](../press-archive-analysis.md): реальная оргструктура с именами, KPI посещаемости, смена ценовой политики, операционные нормативы программ, партнёрства, календарь повторяющихся фестивалей.
- **`_extracted-text.json`** — извлечённый текст всех 87 PDF (через `pypdf`), для полнотекстового поиска по архиву без повторного разбора файлов. Формат: `{"<папка/файл.pdf>": {"pages": N, "text": "..."}}`.
