# Исходные презентации ГЭС-2 / V–A–C

Реальные колоды, переданные заказчиком. Использованы как источник для раздела
«Презентации» в [`../../design-system/design-system.md`](../../design-system/design-system.md) (§9)
и для шаблона `design-system/ges2-presentation-template.pptx`.

| Файл | Что это |
|---|---|
| `organizaciya-koncertov-predlozhenie.pdf` | «Предложение по организации концертов в рамках коммерческого мероприятия». Выдержка на 7 слайдов; внутренняя нумерация доходит до 33 — полной колоды у нас нет. Без партнёрских брендов. |
| `meropriyatie-22-okt-2024.pdf` | Презентация к мероприятию 22.10.2024, совместному с «Газпромбанк» АО. 10 слайдов. Логотип партнёра — только на титуле. |

Фотографии и схемы этажей из этих файлов извлечены в `design-system/photos/`
и `design-system/diagrams/`. Логотип «Газпромбанка» намеренно не извлекался:
это чужой товарный знак, а не бренд-актив ГЭС-2.

**Обе колоды — внутренние рабочие материалы** (коммерческое предложение и
партнёрское мероприятие). Репозиторий публичный — см. предупреждение
в корневом [`README.md`](../../README.md).
