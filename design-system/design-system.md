# Дизайн-система ГЭС-2 — извлечена с сайта

Собрано: 09.08.2026, аудит живого сайта ges-2.org (вьюпорт 1280×720). **Это не придуманная стилистика** — каждое значение ниже измерено через `getComputedStyle()` на реальных элементах прода, методология описана в конце файла.

Важная оговорка: артефакты «Функциональная карта» и «Календарь до конца 2026», которые я делал раньше в этом проекте, использовали мою собственную (придуманную) зелёно-бумажную палитру — она НЕ основана на реальном сайте ГЭС-2. Эта система — первая, которая отражает фактический визуальный язык площадки. Если нужно привести старые артефакты в соответствие с ней, скажите — переделаю.

## 1. Общий характер

Сайт ГЭС-2 **принципиально монохромный**: чёрный текст на белом, без теней, без градиентов, `border-radius: 0` буквально везде. Весь визуальный вес несёт не цвет, а масштаб типографики и белое пространство — это соответствует архитектуре здания («белоснежный завод, оранжерея искусства», Ренцо Пьяно) и позиционированию институции как строгой, но открытой.

Разделители — не привычный 1px, а **hairline 0.5px** (эффект тонкой линии на retina-экранах). Это осознанный выбор в пользу деликатности, а не техническая случайность.

## 2. Шрифт

Один вариативный шрифт в двух начертаниях:

- **Diagramatika Text** — интерфейс, тело текста, эйбрау-лейблы («Выставка», «Медиаторский тур» над названием карточки). Трекинг normal.
- **Diagramatika Display** — заголовки, крупные числа, пункты меню, счётчики событий. Трекинг всегда **+2% от font-size** (не переменное значение — на всех измеренных заголовках ровно 0.02em).

**Это проприетарный шрифт фонда V–A–C.** Файлы недоступны публично и не включены в `tokens.css` — там задан только fallback-стек (`"Helvetica Neue", Arial, sans-serif`). Для боевого использования нужно официально запросить файлы шрифта у ГЭС-2/V–A–C.

## 3. Типографическая шкала

Сайт не использует брейкпоинты с фиксированными rem — вместо этого **fluid-скейлинг**: каждый размер = базовое значение (в px, при эталонной ширине 1440px) × коэффициент вьюпорта.

Формула коэффициента (найдена в inline CSS сайта, footer-компонент):
```
--ges2-scale: calc(min(100vw, 1640px) / 1440);        /* десктоп, потолок 1640px */
--ges2-scale: calc(100vw / 375);                        /* мобильный, < 768px */
```

Измеренная шкала (эталонные px @1440):

| Токен | px @1440 | Где встречен |
|---|---|---|
| `--text-base` | 16 | body, ссылки, кнопки |
| `--text-lg` | 18 | эйбрау-лейблы карточек |
| `--display-sm` | 20 | короткие даты в расписании |
| `--display-md` | 28 | пункты навигации («План здания») |
| `--display-lg` | 40 | счётчики на сегодня («3 выставки,») |
| `--display-xl` | 60 | шаг шкалы (не встречен отдельным элементом, но между 40 и 70 есть 53.33px @1280, что соответствует 60 @1440) |
| `--display-2xl` | 70 | h2 «Сегодня» — крупнейший измеренный текстовый заголовок |

Логотип-словомарка «ГЭС-2» в шапке крупнее любого из этих значений, но реализован не текстом, а отдельным графическим элементом — вне типографической шкалы.

## 4. Отступы

Базовая единица — **5px** (при эталонной ширине 1440px), масштабируется той же fluid-формулой. Измеренные множители: ×1 (5px), ×2 (10px), ×4 (20px), ×6 (30px), ×10 (50px).

## 5. Сетка

На десктопном вьюпорте (1280px) измерено **13 колонок** ≈79.3px с гаттером ≈17.8px между ними. В эталонных единицах @1440 это колонка ≈90px (18 отступных единиц) и гаттер 20px (4 единицы). 13 колонок — не круглое число, характерное для типичных 12-колоночных систем: это осознанный, не «дефолтный» выбор сетки.

## 6. Цвет

| Токен | Значение | Назначение |
|---|---|---|
| `--color-ink` | `#000000` | весь текст, все границы |
| `--color-paper` | `#FFFFFF` | фон |
| `--color-muted` | `#9CA3AF` | второстепенный текст |
| `--color-hint` | `#C0C1C0` | плейсхолдеры |
| `--color-hairline-bg` | `#EEEEEE` | подложки нейтральных блоков |
| `--color-link-utility` | `#2260C5` | найден в бандле — служебный (фокус/интерактивные состояния форм), НЕ визуальный бренд-акцент |
| `--color-error` | `#D30000` | ошибки валидации форм |

Синий и красный — не часть визуального языка сайта в обычном смысле (посетитель их почти не видит), это техническая служебная палитра форм. **У ГЭС-2 нет фирменного цветного акцента** — идентичность держится на типографике и пропорциях, а не на цвете.

## 7. Границы и форма

- `border-radius: 0` — без исключений на всех обследованных элементах.
- Разделители — `0.5px solid #000000` (hairline).
- Теней и градиентов не обнаружено.

## 8. Как это использовать

`tokens.css` в этой же папке — рабочий файл с custom properties, готовый к подключению. Он реализует fluid-формулы через `calc()` и `@media`, повторяя логику сайта, а не апроксимирует её через rem/брейкпоинты.

```html
<link rel="stylesheet" href="tokens.css">
```

Для любых материалов проекта (внутренние инструменты, презентации, отчёты, если нужно визуально сослаться на бренд ГЭС-2) — это более точная основа, чем моя более ранняя «зелёная» палитра.

## Методология измерения

1. Открыл ges-2.org в браузере, вьюпорт 1280×720.
2. Проверил `document.styleSheets` — внешние CSS-файлы сайта относятся к сторонним библиотекам (react-day-picker, Splide-карусель), не к дизайн-системе.
3. Реальная вёрстка — 8 инлайн `<style>`-тегов (styled-components/styled-jsx), ~39 КБ. В них нашлись fluid-формулы отступов footer-компонента — оттуда взята формула `--ges2-scale`.
4. Основной объём данных получен не парсингом CSS-правил (имена классов хэшированы и нечитаемы), а через `getComputedStyle()` на реальных отрендеренных элементах — это надёжнее и не зависит от структуры селекторов.
5. Собрал: font-family/size/weight/letter-spacing для h1/h2/nav/эйбрау-лейблов/дат, border/border-radius на элементах с видимыми линиями, grid-template-columns/gap на карточной сетке, margin/padding на выборке из ~400 блочных элементов для восстановления шага отступов.
6. Сверил: все нестандартные px-значения (17.78, 24.89, 35.56, 53.33, 62.22 и т.д.) делятся на измеренный коэффициент вьюпорта (0.8889 при 1280px) в круглые числа — это подтверждает, что формула восстановлена верно, а не подобрана приблизительно.
