# ГЭС-2 — рабочий репозиторий проекта

Материалы консалтингового проекта для Дома культуры «ГЭС-2» (музей, концертная площадка и творческие мастерские в Москве, [ges-2.org](https://ges-2.org)): оптимизация процессов, клиентский опыт, внутренние заказчики, эффективность использования ресурсов.

Контекст и как здесь работать — см. [`CLAUDE.md`](CLAUDE.md).

## Структура

```
docs/                        Аналитика, источники данных, входные документы
  site-analysis.md             разбор сайта ges-2.org
  org-map.md                   функциональная карта (кто за что отвечает)
  press-archive-analysis.md    разбор архива пресс-релизов и стратегических документов
  documents-ges2-vac/          87 PDF: пресс-релизы + институциональные материалы 2022–2026
  baza_znaniy/                 исходные данные базы знаний (JSON)
  calendar-data.json           календарь событий, извлечённый с сайта
  *.xlsx, *.docx               входные и рабочие документы (реестр событий, опрос, CX-план)

design-system/                Дизайн-токены, реконструированные с сайта ges-2.org
knowledge-base/                автономная HTML-база знаний для службы работы с посетителями
event-management/              автономный реестр событий (треки, этапы, RACI)
surveys/                        HTML-анкета опроса посетителей
tools/                          скрипты сбора календаря событий с сайта
```

## Автономные инструменты

Три HTML-инструмента в `knowledge-base/`, `event-management/` и `surveys/` — самодостаточные файлы: все данные встроены внутрь, открываются без сервера и интернета, ничего дополнительно скачивать не нужно.

Каждый собирается из исходных данных скриптом на Python (без внешних зависимостей, кроме `openpyxl` для Excel-скриптов):

```bash
python3 knowledge-base/build_kb.py          # из docs/baza_znaniy/ges2_kb_data.json
python3 event-management/build_registry.py  # из docs/ges2_event_pm_template.xlsx
python3 tools/fetch_calendar.py --from 2026-08-09 --to 2026-12-31 --out docs/calendar-data.json
python3 tools/build_calendar_xlsx.py        # из docs/calendar-data.json
```

Если меняете исходные данные — пересоберите соответствующий инструмент, не редактируйте `index.html`/`.xlsx` напрямую (они перезаписываются при следующей сборке).

## Важно перед публикацией/расшариванием

`docs/documents-ges2-vac/` и часть материалов в `docs/` содержат внутренние документы ГЭС-2/V–A–C (институциональные планы, состав руководства, финансовые показатели программ), не предназначенные для публичного распространения без согласования с ГЭС-2. Держите репозиторий приватным, если явно не согласовано иное.
