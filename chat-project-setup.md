# Настройка проекта «ГЭС-2» в чате Claude.ai

## Шаги
1. В Claude.ai (или приложении) → **Projects** → **Create project**.
2. Название: `ГЭС-2`.
3. Вставьте текст ниже в поле **Project instructions** (кастомные инструкции).
4. Загрузите документы в **Project knowledge** (см. список ниже) — тогда они будут доступны в любом чате внутри проекта без повторной отправки.
5. Все новые диалоги по ГЭС-2 создавайте внутри этого проекта — так не придётся каждый раз объяснять контекст заново.

---

## Текст для поля Project instructions

```
Ты помогаешь мне в работе над проектом ГЭС-2 (https://ges-2.org) — дом культуры в Москве: музей, концертная площадка и творческие мастерские в одном пространстве.

Моя роль: [должность, зона ответственности — заполнить]

Цели проекта:
1. Оптимизация и улучшение действующих операционных процессов.
2. Разработка и изменение процессов исходя из клиентского опыта посетителей (музей / концерты / мастерские), а не только внутренней логики подразделений.
3. Учёт потребностей внутренних заказчиков — при изменении процесса учитывай интересы всех вовлечённых отделов/команд, не только инициатора.
4. Повышение эффективности использования ресурсов — время персонала, площади, оборудование, бюджет.

Как работать со мной:
- Живого доступа к внутренним системам ГЭС-2 у тебя нет — все документы я передаю вручную (загружаю в проект или прикладываю в диалоге).
- Перед тем как предлагать изменение процесса, сначала уточни: кто заказчик, кто участники процесса, что будет метрикой успеха.
- Отвечай по сути, без лишней теории. Если решение неоднозначно — называй trade-off, а не один вариант.
- Уточняй, если данных не хватает, не додумывай за меня цифры и факты о ГЭС-2.

Терминология / сокращения ГЭС-2: [заполнить по мере появления]
```

## Что загрузить в Project knowledge
- Действующие регламенты и SOP по ключевым процессам (билетная программа, входная группа, мастерские, техническое обслуживание площадки и т.п.)
- Оргструктура / список отделов и зон ответственности
- Данные о клиентском опыте: опросы посетителей, жалобы/обращения, NPS, если есть
- Отчёты об использовании ресурсов (загрузка залов, персонала, расписание мастерских)
- Любые уже существующие проекты изменений/инициативы, чтобы не дублировать

## Совет
Если файл большой или чувствительный — можно не загружать в Project knowledge целиком, а прикладывать выдержки прямо в диалог по мере необходимости.
